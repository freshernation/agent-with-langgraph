# Week 1 — You already wrote this

> **Destination**
> Desk, the agent you wrote by hand, rebuilt as a LangGraph graph that behaves the
> same way — and both traced in Langfuse, side by side, so you can say exactly what
> the framework did for you and what it took away.

You are not learning an agent this week. You are learning a **way of writing down**
an agent you already understand.

## The rule from this week on

**Draw it before you write it.** Every graph in this course starts on paper: the
nodes, the edges, and what the state holds at each step. If you cannot draw it, you
cannot defend it on Friday.
